# Major

Bem-vindo à cidade de Major!

## Sobre

Major é uma cidade desenvolvida para o jogo GTA V utilizando a framework vRP. A linguagem de programação utilizada é Lua.

## Estrutura

A cidade possui diversos recursos e scripts organizados em diferentes pastas, incluindo empregos, mapas, sistema de voip, e muito mais.

## Framework

- **Framework**: vRP
- **Linguagem**: Lua
